https://github.com/Bengerthelorf/macIconChanger/

早速試すために Release ページからダウンロード＆インストール！

### ここからは慎重に

このアプリは普通のアプリとは一味違います、FontForge と同じタイプで、セキュリティに引っかかります、インストールするところまでは普段と変わらないと思うのですが、いざ開こうとすると開けません

![warning](/images/df5a7a2f0abe4c/warning.png)
*ひとまず「完了」を押しましょう*

セキュリティ上仕方がないことだと思うし、確か開発者側がライセンス料を払わないと解決しない問題だったはずなので、フリーのこういうちょっとしたことを便利にするアプリだとしょうがないことです

解決策は「設定」→「プライバシーとセキュリティ」→ 一番下までスクロールして「このまま開く」というボタンをクリックします

![kaiketsuone](/images/df5a7a2f0abe4c/kaiketsuone.png)
*分かりづらい場所にあるね*

画像は割愛しますが、クリックしたあとにまたポップアップが出ると思うので真ん中の「このまま開く」を押し、Touch ID やパスワードでシステム認証をして開きます

私のバージョンでは、アップデートが出来ませんみたいな通知が表示されましたが、まあ無視していいと思います

ここまで普段とは違う方法でしたが、さらに！必要なことがまだあります

### さらなる強敵が待っていた

これはちょっと間違えればシステムを破壊することになるかもしれないが、アプリと OS の仕組み上動かすのに必要なもののため、慎重に間違えずに出来る精神と時間の余裕があるときに行うのがおすすめです

ターミナルを開きましょう、私は Ghostty と Fish を使っています、めっちゃおすすめですが、標準の Terminal.app と zsh でも全然問題ないです、むしろそっちのほうが普通です

![ghostty](/images/df5a7a2f0abe4c/ghostty.png)
*Ghostty と Fish の組み合わせ、結構いいよ*

```shell
cd /Applications/Utilities/
sudo visudo
```

パスワードを入力してください

### ここ大事

うわ、なんだこれとなる画面だと思います、私もつい先月くらいだったら無理だったかも（最近、久しぶりの Linux として Void Linux に挑んでいて結構鍛えられて、なんか慣れた）

やることは `ALL ALL=(ALL) NOPASSWD: /Users/kyohei/.iconchanger/helper.sh` を追加することで、意味は IconChanger（今紹介してるアプリ）にアプリアイコンを変更する権限を与えるっていうものです、オープンソース（ソースコード見てもわからないけども）だし、Reddit の見つけた投稿でも高評価だったし、スター数も400以上あるし、今日か昨日に新しいバージョンがリリースされて、継続的な改善が続けられているものなので安心して適用してください、確かに私自身にも少し怖い気持ちはありますけども

![visudo](/images/df5a7a2f0abe4c/visudo.png)
*vim です、操作感がめっちゃ独特な*

以下の操作をそのまますれば大丈夫です

1. 以下をコピーする

```
# IconChanger Shudo
ALL ALL=(ALL) NOPASSWD: /Users/kyohei/.iconchanger/helper.sh
```

:::message
**注意**：`/Users/kyohei` の部分は自分のユーザー名に置き換えてください、`$HOME` 使えるかなと思ったんですが、試してみたら無理だったため、すみません

**例**：`kumadesu` なら

```
# IconChanger Shudo
ALL ALL=(ALL) NOPASSWD: /Users/kumadesu/.iconchanger/helper.sh
```

になります
:::

1. 半角モードにした上で、`I` キーを押し、編集モードに入る
2. ↓ 下ボタンを6回押す、Enter キーを2回、↑ 上ボタンを1回押す
3. `shift` + ⌘ `command` + `V` を押す
4. `esc` キーを押し、`:wq` を入力し、閉じる

はい終わり！（ ⌃ `control` + `command` + `space` で絵文字一覧を開ける）

あとはアプリを再起動すれば！開けた！
